1. Problem Statement

In many communities, reporting infrastructure problems and public safety concerns is slow and disorganized:

  • Citizens do not know where to report community problems.
  • Administrators receive reports through different, disconnected channels.
  • Duplicate reports about the same problem create unnecessary work.
  • Choosing the right response team for each incident is difficult.
  • Citizens cannot see whether their reports are being handled.
  • Administrators lack centralized analytics and reporting tools.

2. Proposed Solution

ResQ is a centralized, API-driven platform where citizens report incidents with a description, photographs and a map location. An AI service analyzes each report to suggest a category, priority level, short summary and responsible department, and detects possible duplicates. Administrators review the AI suggestions, approve incidents and assign response teams, who update progress until the incident is resolved. Everyone is kept informed through real-time notifications and emails, and administrators monitor everything through a dashboard with charts and reports.

3. Project Objectives

  • Build RESTful Web APIs for all modules using ASP.NET Core and C#.
  • Store data in SQL Server using Entity Framework Core.
  • Secure the system with ASP.NET Core Identity, JWT and role-based authorization.
  • Integrate an AI service for classification, priority, summarization, department recommendation and duplicate detection.
  • Integrate interactive maps (Leaflet + OpenStreetMap) and an email delivery service.
  • Provide real-time notifications using SignalR.
  • Implement incident assignment and tracking workflows.
  • Provide an administrator dashboard, analytics and exportable reports.
  • Deliver a professional, responsive user interface.
